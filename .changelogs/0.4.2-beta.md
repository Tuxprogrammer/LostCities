# 0.4.2-beta

For GT New Horizons 2.9.1. Same install: one jar on the server and every client. Worlds made with 0.4.1-beta keep working.

## Fixed
- GT New Horizons 2.9.1: the server no longer stops with `NoSuchFieldError` while generating the first chunks. RWG2 2.0.9 moved its continent, island, landmark-offset and village settings out of `ConfigRWG`; the mod now reads each setting from its 2.0.9 home, falling back to `ConfigRWG` on RWG2 2.0.6. 2.9.1 is the supported pack from this version on.

## Changed
- Built against the 2.9.1 versions of RWG2 (2.0.9), GTNHLib (0.11.58), VillageNames (4.5.22-GTNH) and Applied Energistics 2 (rv3-beta-1104-GTNH).

## Added
- New manual test scenario `perf.walk` (test hooks only) walks a player across fresh ground and logs the server's tick times (mean, p95, p99, slowest tick), and `perf.sites` now splits chunk loading into its parts. Chunk generation speed and the generated world are unchanged from 0.4.1-beta.

## Upgrade notes
- The GTNH 2.9.1 server pack creates new worlds as RWG2 Continents (`level-type=rwg2_continents`); 2.9.0's server pack created classic RWG. An existing world keeps the type it was made with.
- Et Futurum 2.6.66, new in 2.9.1, adds ruined portals and shipwrecks. They are rare and are not kept out of cities; if you find one inside a city, please report it with its coordinates.
