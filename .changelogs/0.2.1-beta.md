# 0.2.1-beta

Hotfix for 0.2.0-beta. Same install: one jar on the server and every client, GT New Horizons 2.9.0. Worlds made with 0.2.0-beta keep working.

## Fixed
- Single-player crash (`ArrayIndexOutOfBoundsException` in `FootprintGuard.drops`) when the client applied a block update while the integrated server was populating a chunk. The worldgen guard now never runs for the client's world.

See the [0.2.0-beta notes](https://github.com/Tuxprogrammer/LostCities/releases/tag/0.2.0-beta) for the city-realism changes.
