# 1.20 mechanisms and their 1.7.10 counterparts

Every Minecraft 1.20.1, Forge 47 or Java 17 mechanism that upstream Lost Cities (`1.20` at `f18a094d`) relies on, merged and deduplicated from the "1.20 dependencies" tables of all nine areas, with the 1.7.10 counterpart where an area named one. "None — decided in the new spec" means no area named a counterpart, or an area stated that none exists. This file records the gap; it does not design the answer, which belongs in [docs/new-spec/](../new-spec/README.md).

**Used by** names the areas (by folder) and, in parentheses, the classes, assets or sheets involved. Area tables keep their own wording and remain the detailed source.
